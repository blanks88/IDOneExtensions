# itiaOS — IDOneExtensions

- [Documentación](docs/README.md): funcionamiento actual del proyecto.
- [Cambios y features](changelog/README.md): planes agrupados por identidad de cambio.
- `tmp/`: almacenamiento temporal ignorado por Git; no contiene documentación canónica.

La convención del repositorio usa `.itia/`. Los cambios se registran como
`YYMMDD-NNN-TIPO-SLUG`; los planes viven en `plans/<plan>/PLAN.md`.
Los informes de desarrollo y QA se crean cuando exista trabajo o revisión asignada.
